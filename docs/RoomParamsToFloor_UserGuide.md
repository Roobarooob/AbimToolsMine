# Передача параметров из помещений в элементы отделки

## Назначение инструмента

Инструмент **«Элементы отделки — Заполнить параметры»** переносит значения параметров помещений в параметры элементов отделки:

- полов;
- потолков;
- стен.

Например, номер, этаж, секцию и группу спецификации помещения можно записать в соответствующие параметры пола, потолка или стены, относящихся к этому помещению.

> **Важно.** Инструмент изменяет значения параметров в активной модели Revit. Перед массовой обработкой рекомендуется проверить настройки на нескольких помещениях.

## Что должно быть подготовлено в модели

### Помещения

Для корректной работы:

- помещения должны находиться в активной модели, а не в связанном файле;
- помещения должны быть размещены;
- помещения должны быть замкнуты и иметь площадь больше нуля;
- элементы отделки должны геометрически примыкать к соответствующим помещениям;
- параметры-источники должны быть заполнены у помещений.

Неразмещённые, незамкнутые и не имеющие площади помещения не обрабатываются.

### Элементы отделки

Инструмент обрабатывает элементы только в активной модели.

| Выбранная категория | Какие элементы обрабатываются |
|---|---|
| **Полы** | Полы, имя типа которых начинается с `ВО Пол` или `ВО Стена` |
| **Потолки** | Все элементы категории «Потолки» |
| **Стены** | Стены, имя типа которых начинается с `ВО Стена` |

Продолжение имени типа может быть любым. Например, подойдут:

- `ВО Пол Плитка`;
- `ВО Пол Линолеум`;
- `ВО Стена Окраска`;
- `ВО Стена Плитка`.

Регистр букв не имеет значения, но начало имени должно соответствовать указанному правилу.

### Параметры

В каждой строке таблицы указываются два имени:

- **Параметр помещения (источник)** — откуда взять значение;
- **Параметр элемента отделки (цель)** — куда записать значение.

Чтобы перенос сработал:

1. Параметр-источник должен существовать у помещения.
2. Параметр-источник должен содержать значение.
3. Параметр-цель должен существовать у экземпляра пола, потолка или стены.
4. Параметр-цель не должен быть только для чтения.
5. Тип данных параметра-цели должен позволять записать полученное значение.
6. Имена параметров в таблице должны совпадать с именами в Revit.

Для стандартных параметров помещения `Номер` и `Имя` можно использовать именно эти названия.

По умолчанию предлагаются следующие соответствия:

| Параметр помещения | Параметр элемента отделки |
|---|---|
| `Номер` | `ПРО_Номер помещения` |
| `ПРО_Этаж` | `ПРО_Этаж` |
| `ПРО_Секция` | `ПРО_Секция` |
| `ПРО_Группа спецификации` | `ПРО_Группа спецификации` |

Если в вашем проекте используются другие имена, измените их в таблице перед запуском.

## Работа с окном инструмента

>
> _Вставьте скриншот окна с подписями основных областей: таблица соответствий, категории, помещения, кнопка «Запустить»._

### 1. Настройте таблицу соответствий

Каждая строка задаёт одно правило переноса:

```text
Параметр помещения → Параметр элемента отделки
```

Можно:

- изменить существующие строки;
- добавить строку через пустую строку внизу таблицы;
- удалить ненужную строку: выделить её и нажать `Delete`;
- оставить пустую строку — она будет пропущена при обработке.

После редактирования ячейки щёлкните по другой строке или области окна, чтобы завершить ввод значения.

> 📷 **Место для скриншота 3 — пример заполненной таблицы соответствий**
>
> _Покажите несколько строк с параметрами помещения и параметрами элементов отделки._

### 2. Выберите категории элементов

Установите флажки для элементов, которые требуется обработать:

- **Полы**;
- **Потолки**;
- **Стены**.

Можно выбрать одну, две или все три категории. Если не выбрана ни одна категория, обработка не запустится и в окне появится предупреждение.

Состояние флажков сохраняется, когда окно временно закрывается для выбора помещений на виде.

### 3. Выберите режим обработки помещений

Доступны два режима.

#### Все помещения

Инструмент рассматривает все размещённые помещения активной модели, имеющие площадь больше нуля.

Этот режим удобен для заполнения всего проекта или всего открытого файла.

#### Выбранные помещения

Инструмент обрабатывает отделку только выбранных помещений.

Если помещения были выделены в Revit до переключения режима, они автоматически попадут в выборку. Выделенные стены, полы и другие элементы будут проигнорированы.

Если подходящих помещений в текущем выделении нет, появится сообщение **«Помещения не выбраны»**.

Для ручного выбора:

1. Выберите режим **«Выбранные помещения»**.
2. Нажмите **«Выбрать на виде...»**.
3. Выберите одно или несколько помещений в модели.
4. Нажмите **«Готово»** на панели выбора Revit.
5. Окно инструмента откроется снова и покажет количество выбранных помещений.

> 📷 **Место для скриншота 4 — режим «Выбранные помещения»**
>
> _Покажите кнопку «Выбрать на виде...» и строку с количеством выбранных помещений._

### 4. Запустите обработку

Перед запуском проверьте:

- соответствия параметров заполнены правильно;
- выбрана хотя бы одна категория отделки;
- в режиме выбранных помещений указано хотя бы одно помещение;
- имена типов элементов соответствуют требованиям;
- параметры назначения добавлены к элементам отделки.

Нажмите **«Запустить»**. Во время работы появится окно прогресса. После завершения Revit покажет сообщение **«Данные успешно записаны»**.

## Что происходит с существующими значениями

Если параметр-цель уже заполнен, его значение может быть заменено значением из найденного помещения.

Если у помещения отсутствует указанный параметр или получить его значение невозможно, соответствующая строка для этого элемента пропускается. Остальные соответствия продолжают обрабатываться.

## Закрытие окна

Крестик в правом верхнем углу закрывает окно без запуска обработки.

Чтобы последнее изменение в активной ячейке таблицы было зафиксировано, перед закрытием или запуском завершите редактирование — щёлкните по другой строке либо по свободной области окна.

## Если параметры не заполнились

Проверьте следующие причины.

### Элемент не попал в обработку

- Не установлен флажок его категории.
- Элемент находится в связанном файле.
- Имя типа пола не начинается с `ВО Пол` или `ВО Стена`.
- Имя типа стены не начинается с `ВО Стена`.
- Элемент не примыкает к помещению или расположен на другой высоте.
- В режиме выбранных помещений соответствующее помещение не было выбрано.

### Помещение не найдено

- Помещение не размещено.
- Помещение не замкнуто.
- Площадь помещения равна нулю.
- Между элементом отделки и помещением есть значительное геометрическое смещение.
- Пол находится не под помещением, потолок — не над ним, либо стена не граничит с помещением.

### Значение не записалось

- Имя параметра в таблице введено с ошибкой.
- Параметр-источник отсутствует у помещения.
- Параметр-источник не заполнен.
- Параметр-цель отсутствует у экземпляра элемента отделки.
- Параметр-цель доступен только для чтения.
- Формат значения не соответствует типу параметра-цели.

## Краткий порядок работы

1. Проверьте размещение и границы помещений.
2. Проверьте имена типов полов и стен.
3. Добавьте необходимые параметры к элементам отделки.
4. Откройте **«Элементы отделки — Заполнить параметры»**.
5. Настройте таблицу соответствий.
6. Выберите категории отделки.
7. Выберите все помещения или только нужные.
8. Нажмите **«Запустить»**.
9. Проверьте заполненные параметры на нескольких элементах.
